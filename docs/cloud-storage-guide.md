# 开启免费云存储 · 操作指南（含「云开发按钮灰色」排查）

目标：把菜谱照片免费存到云端，换手机 / 重装也不丢。**全程免费，不用买服务器、不用备案。**

---

## 一、先看这一步：为什么你的「云开发」按钮是灰的

**现象**：开发者工具顶部「预览 / 真机调试」正常是白色，「**上传**」和「**云开发**」却是灰色点不动。

**原因（已经确认）**：这个项目当前绑定的 AppID 属于**小程序测试号**。
判断依据：打开 `详情 → 基本信息`，账号名显示为「**×××的小程序测试号**」。

**测试号是什么**：微信开发者工具提供的一个**临时沙箱**，用来试写成写代码。它没有真实主体，因此：

| 能力 | 测试号 |
|---|---|
| 模拟器里跑、点「预览」扫码在手机上用 | ✅ 可以 |
| 「上传」代码 / 做体验版 | ❌ 不行（按钮灰） |
| 云开发（云存储 + 云数据库） | ❌ 不行（按钮灰） |

所以本地模式的功能一切正常，**只是云存储这条路被测试号堵住了**。

> 30 秒自查：点 `详情 → 基本信息 → Appid` 右边的「**修改**」，如果列表里有你自己注册的正式小程序，
> 直接选中就能用（跳到下面第二步）；如果没有，就去注册一个。

## 二、三步开启（约 10 分钟）

### 第 1 步：注册一个正式的小程序（个人主体，免费）

1. 打开 **mp.weixin.qq.com** → 「立即注册」→ 选择 **小程序**
2. 用一个**没注册过公众号/小程序**的邮箱注册 → 去邮箱点激活链接
3. 主体类型选 **个人** → 填身份证信息 → 微信扫码实名
4. 注册完成后，左侧「**开发管理 → 开发设置**」里就能看到 **AppID**（`wx` 开头的一串）

> 这一步**不需要** 300 元的微信认证。认证只影响支付、微信搜索等能力，**云开发不需要认证**。
> 一个微信号最多可以拥有 5 个小程序，够用。

### 第 2 步：把项目切到这个新 AppID

两种做法，任选一种（推荐 A）：

- **A（图形界面）**：微信开发者工具 → `详情 → 基本信息 → Appid 右侧「修改」` → 选中刚注册的小程序 → 重新编译。
- **B（改文件）**：编辑项目根目录 `project.config.json`，把 `"appid": "wx…"` 换成新 AppID。

> ⚠️ **换 AppID 之后，手机上之前录入的菜谱和菜单会看不到**——小程序的本地存储是按 AppID 隔离的。
> 目前只有几道菜，重新录一遍即可（约 5 分钟）；一旦开了云模式，数据就长期存在云端，不再受换号影响。

### 第 3 步：开通云开发 + 建集合 + 填环境 ID

1. 开发者工具顶部点「**云开发**」→ 按提示开通 → 创建一个环境（套餐选**免费**）
   → 记下那串**环境 ID**（形如 `cloud1-xxxxxxxx`）
2. 进入云开发控制台 → 左侧「**数据库**」→ 新建两个集合：**`dishes`** 和 **`orders`**
3. 两个集合的权限都改成「**仅创建者可读写**」
   （别设成「所有人可读」：否则别人能往你的库里灌数据；设成「仅管理端可写」你自己也写不进去）
4. 打开 `miniprogram/config.js`，把 `cloudEnv: ''` 改成 `cloudEnv: 'cloud1-xxxxxxxx'`
5. 回到开发者工具点「**编译**」

完成。之后你在菜谱页上传的照片会自动进微信免费云存储，**换手机 / 重装都不丢**。

## 三、后台的「备案与认证」「版本管理」要不要点？

打开 mp.weixin.qq.com 后台会看到这三项，**家庭自用都不用做**：

| 后台项目 | 要做吗 | 原因 |
|---|---|---|
| **小程序备案**（ICP 备案） | ❌ 不用 | 官方在这个页面上就写了「**可与代码开发并行，在小程序上架发布前完成即可**」。不上架 → 用不到 |
| **微信认证**（300 元/年） | ❌ 不用 | 只影响「被搜索 / 被分享」能力，页面写明「不影响后续版本发布」。**个人主体开通云开发也不需要认证** |
| **版本管理**（上传代码 → 提交审核 → 发布） | ❌ 不用 | 这是「正式上架」的流程。家庭自用走开发者工具「**预览**」扫码即可 |

> ⚠️ **红线：不要点「上传代码 / 提交审核 / 发布上线」。**
> 一旦正式上线：① 免费云环境会在**上线后第 15 天**到期要付费；② 会触发 ICP 备案要求。
>
> 唯一例外：如果开通云开发时系统提示「**请先完成备案**」，那就按提示去备案
> （**备案本身免费**，只是要等通信管理局审核，通常几天到 20 个工作日）。个人主体小程序开通云开发通常不需要。

## 四、费用边界（2026 年政策，说清楚免得担心）

- 新用户可以创建**免费云环境**，免费额度含：云存储约 **5GB**、云数据库约 **2GB**（以官方最新公告为准）。
  几十道菜的图文，几年都用不完。
- **只要不把小程序「发布上线」，免费环境就一直不用续费。** 家庭自用只在开发者工具点「预览」扫码，
  或用「体验版」，完全够。
- 一旦正式发布上线，免费环境会在**上线后第 15 天**到期，届时需升级基础套餐（19.9 元/月）。
  → 所以**家庭自用不要上线**。
- 家庭自用也**不需要 ICP 备案**（备案是"发布上线"的前置条件，不走上线就不用备案）。

### 关于「真机调试 / 预览」的临时上传（不算发布，不用担心）

点工具栏「**真机调试**」或「**预览**」时，工具会提示"正在上传代码"——这只是把代码**临时送到微信的调试/预览服务器**，让手机能跑起来调试。**它不会**进入"版本管理 → 开发版本"列表，更不会"发布上线"。

- ✅ 不会触发免费云环境到期（只有「发布上线」才触发"上线后第 15 天到期"）
- ✅ 不会触发 ICP 备案
- ✅ 不会产生任何扣费
- 自行验证：打开 mp.weixin.qq.com → 管理 → 版本管理 → 「开发版本」列表为空（或无新条目）即证明只是调试态临时上传

> 反而建议：用真机调试在手机上给某道菜传一张封面图，再去云开发控制台「存储」看有无文件，可直接验证云端链路是否打通。

## 五、如果暂时不想折腾

完全可以先保持现状（**本地模式**）：

- 全部功能都能正常用，照片和菜谱存在手机本机；
- 代价：**换手机或重装微信 / 清除缓存后会丢**，需要重新录入；
- 想上云的时候，再回来按上面的三步做即可，**代码不用改任何一行**。

## 附：GitHub 与照片的分工

- **GitHub** 只存**代码**（备份 + 二次开发）。
- **照片**走**微信云存储**（免费）或手机本地，不会进 GitHub。

两者各管一摊，别混。
